po — pipe-friendly code runner (Play Over)

Usage: po [options]
       po -kill [options]
       po -start [options]

Reads a piece of code from stdin, runs it, and prints the result. Meant
for piping a shell snippet (or a selection from an editor like helix) into
a small persistent context: values a script writes via $SETENV are carried
over to the next invocation in the same context.

Recognized stdin shapes (checked in order):
  ```lang            fenced code block (``` or ~~~), language hint optional
  code
  ```
  `code`             single-backtick inline block
  #!/usr/bin/env sh  a script starting with a shebang line
  code
Anything else is an error.

Supported runtimes: sh, bash (more planned: python, ruby, go, lua)

A background daemon holds the context (env values) for the duration of
its process. It is started automatically on first use and can be
controlled directly:
  -kill   stop the daemon for the current context
  -start  start the daemon for the current context and wait (foreground)

Options:
  -h, --help     show this help
  -v             show version
  -x <CONTEXT>   context name (EDC_PO_CONTEXT), case-insensitive
  -o <FORMAT>    output format (EDC_PO_OUT_FMT): md (default) | hash
  -i             print stdin before the result (EDC_PO_PRINT_STDIN=1)
  -ni            don't print stdin before the result

Env vars:
  EDC_PO_CONTEXT      default context name
  EDC_PO_PRINT_STDIN  if true/1/yes, -i is the default
  EDC_PO_OUT_FMT      md | hash
  EDC_PO_PRINT_EXIT   if true/1/yes, print exit code + elapsed time

Examples:
  echo '```sh
echo hi
```' | po

  cat script.sh | po -x myproj -o hash
